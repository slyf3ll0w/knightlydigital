# Quality-of-life batch 1 — 2026-10-06

David's first QoL batch. Branch `qol-batch-1`.

## What changed

1. **Create → Call / Message open a picker in place.** The phone Create
   sheet's Call and Message tiles no longer navigate. Each opens a bottom
   sheet with a search field (`components/ReachPicker.tsx`) listing clients,
   leads and contacts:
   - **Call**: only people with a phone number. Tap a row → it dials right
     away (business line when set up, else the phone's own dialer). A typed
     10-digit number shows "Call (xxx) xxx-xxxx". A **Keypad** row at the
     bottom opens the Calls page keypad.
   - **Message**: tap a row → their thread. A typed number starts a new
     thread when the company has a line (unchanged behavior). The inbox's
     `New message` button uses the same picker.
2. **Unread client messages are counted** on the Create `+` button, on the
   Create sheet's Message tile, and on the More sheet's Messages tile
   (the desktop rail already had it). Opening a thread takes its messages
   off the count at once (it used to miss the update on a navigation and
   wait for the next 20 s poll — the thread's recount event fired before
   the shell re-attached its listener).
3. **Back on a lead goes to Leads.** A lead's page (`/app/contacts/[id]`,
   status LEAD) points its desktop back arrow at `/app/leads`, and the
   phone back pill falls back to Leads when there's no page under it
   (notification tap, deep link) via `components/BackParent.tsx`.

## Test recipes (phone unless noted)

1. Tap `+` → **Call**. A "Call" sheet slides up over the current page with a
   search field. Type part of a client's name → their row shows; tap it →
   the call starts (business line) or the phone dialer opens.
2. In the Call sheet type a full 10-digit number nobody has → a "Call (…)"
   row appears at the top; tap it → it dials.
3. In the Call sheet tap **Keypad** at the bottom → the Calls page opens
   with the keypad up.
4. Tap `+` → **Message** → a "New message" sheet with search; tap a client →
   their thread opens.
5. Have someone text / portal-message you (1 message). Within ~20 s the `+`
   button shows a red **1**; open it → the Message tile shows **1**; open
   More → the Messages tile shows **1**.
6. Two different clients message you → the badges read **2**. Open one
   thread → the badges drop to **1** right away. Open the other → they're
   gone.
7. Leads → tap a lead → tap the back pill (phone) / back arrow (desktop) →
   you land on **Leads**, not Clients.
8. Open a lead from a notification (or reload on their page) → the back
   pill reads **Leads** and goes there.
9. A client (not a lead) still goes back to **Clients**.
