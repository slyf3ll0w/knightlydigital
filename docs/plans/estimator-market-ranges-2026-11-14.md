# US home-service price ranges for estimator tests (researched 2026-11-14)

## How to read this file

- All prices are what a US homeowner pays, labor + materials, unless the Notes column says otherwise.
- **Evidence level** is given in Notes for every row:
  - **[page]** = I fetched the page itself and the figure was read from the page text.
  - **[snippet]** = Angi, HomeGuide and HomeAdvisor returned HTTP 403 to direct fetches, so these figures come from the search engine's extract of that page (URL given). They are the site's published numbers as quoted by search, not independently re-read. Spot-check before treating as exact.
  - **[weak]** = only found on low-authority / SEO pages; do not use as a hard test bound.
- "not found" = no published figure located. Nothing here is estimated by me. Where I did arithmetic it is labelled "derived".
- Source short names: Angi = angi.com, HG = homeguide.com, HA = homeadvisor.com, TOH = thisoldhouse.com.
